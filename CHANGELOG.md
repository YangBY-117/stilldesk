# Changelog

## 0.1.0 — 2026-11-07

First public StillDesk source release.

- Unified CLI, MCP stdio router, and an authenticated local Streamable HTTP
  transport with explicit provider/capability states.
- Background-only Chrome and Edge extension control through Native Messaging;
  no browser debugging connection or debugger permission.
- Repaired WeChat read backend and improved QQ pagination/context, with legacy
  foreground send/download execution removed from the public default path.
- Fixed Feishu official-CLI operations and Tencent Meeting cloud/local adapters;
  account permissions, models and native prerequisites remain explicit.
- Fifteen documented client configuration targets and portable desktop plugin
  files. Claude Code verification is static only.
- Reproducible browser fixtures, native transport tests, independent sanitizer,
  capability matrix, a public website, brand assets and a test-ledger animation.
- Source acquisition verifies bounded streaming content fingerprints, copied
  bytes and final database/WAL identity. Same-size writes hidden by delayed file
  metadata invalidate the cache; cached-index reads remain available explicitly.

Current native WeChat writes, uncached network media retrieval, QQ personal
account writes, native browser dialogs and trusted-user-gesture actions are not
claimed by this release.
